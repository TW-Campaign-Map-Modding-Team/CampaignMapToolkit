# Contributing workflow

1. Branch from `main` and give the branch a meaningful name.
2. Commit your changes and push the branch.
3. Run the full test suite locally and make sure it is green before opening the
   pull request. A pull request with failing tests is not ready; do not open it
   and wait for CI to tell you what a local run would have. See
   [Building and testing](building-and-testing.md).
4. Open a pull request against `main` and assign @victimized0,
   @robert-d-schultz, or @MrJox as reviewer.
5. If the review returns the pull request, make the requested changes and
   request another review.
