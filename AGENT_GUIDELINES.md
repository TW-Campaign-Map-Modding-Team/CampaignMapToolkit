# Agent Guidelines

The guidelines for working in this repository, for everyone working in it,
human or agent. This is the single source of truth; `AGENTS.md` and
`CLAUDE.md` only point here.

Each document covers one concern:

- [Coding style](guidelines/coding-style.md) — how C# is written here.
- [Documentation](guidelines/documentation.md) — what documentation is for and
  what it may claim.
- [Repository layout](guidelines/repository-layout.md) — where things go.
- [Agent skills](guidelines/agent-skills.md) — reusable skills and scripts, and
  how to make Claude Code find them.
- [Building and testing](guidelines/building-and-testing.md) — how to build the
  solution and run the tests.
- [Output compatibility](guidelines/output-compatibility.md) — the
  byte-exactness rules for everything that writes game-ready files.
- [Contributing workflow](guidelines/contributing-workflow.md) — branches,
  pull requests, and review.
